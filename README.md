# Pulse — desktop-плеер (Electron)

Музыкальный сервис в духе Spotify с тёмной темой и розовым акцентом: анимированный hero-блок,
карточки плейлистов с hover-эффектами, полноценный плеер снизу (play/pause, next/prev, shuffle,
repeat, seek, громкость), очередь треков, живой поиск, жанры, лайки.

## Запуск

Нужен установленный Node.js (18+) и интернет-соединение (каталог грузится из Deezer).

```bash
npm install
npm start
```

Откроется desktop-окно приложения.

## Структура

```
main.js              — главный процесс Electron (окно, кастомный титлбар, прокси к Deezer API)
preload.js            — безопасный мост: управление окном + window.pulseMusic.request(path)
renderer/
  index.html          — разметка интерфейса
  styles.css           — вся дизайн-система: цвета, типографика, анимации
  renderer.js          — загрузка каталога из Deezer + логика плеера/навигации
```

## Откуда музыка

Приложение подключено к **Deezer Open API** (бесплатно, без ключа и регистрации): реальные
исполнители, включая русскую сцену (Земфира, Мумий Тролль, Баста, Макс Корж, Скриптонит,
Клава Кока, Ленинград и др.), настоящие обложки, живой поиск по всему каталогу.

**Важно:** каждый трек — это официальный **30-секундный превью-фрагмент**. Это ограничение
самого Deezer (действует даже без подписки), а не баг приложения — полноценный стриминг целых
треков доступен только по платному партнёрскому API (Spotify/VK/Яндекс.Музыка выдают такие
ключи исключительно под лицензионное соглашение); бесплатного легального способа получить
полные треки не существует.

Все сетевые запросы к Deezer выполняются в **главном процессе Electron** (`main.js`), а не в
окне (renderer) — так проще обойти CORS-политику Deezer и не открывать сетевой доступ напрямую
в интерфейс. Рендерер обращается к нему через `window.pulseMusic.request(path)` (см.
`preload.js`), IPC-хендлер — `main.js` (`ipcMain.handle('deezer:request', ...)`).

При старте приложение подтягивает:
- топ-треки нескольких русских/СНГ исполнителей → раздел «Русская сцена»
- мировой чарт треков и альбомов → «Треки дня» и «Популярные альбомы»
- живой поиск по вводу в поисковой строке (debounce 350мс)

Если интернета нет или Deezer недоступен — секции покажут сообщение об ошибке загрузки вместо
зависания интерфейса; клик по треку без превью просто ничего не делает.

### Хочешь свои mp3 вместо 30-секундных превью

Единственный легальный вариант — использовать собственные аудиофайлы:

1. Положи файлы в `renderer/audio/track-<id>.mp3`.
2. В функции `mapTrack()` (`renderer/renderer.js`) подставляй свой путь вместо `t.preview`.
3. Остальной плеер трогать не нужно — он уже работает через настоящий тег `<audio>`.

## Вход и регистрация (Firebase Auth)

Экран логина/регистрации подключён через **Firebase Authentication** (email + пароль,
бесплатный план Spark). Пока конфиг не вставлен, приложение показывает предупреждение и
даёт войти кнопкой «Продолжить как гость» — чтобы можно было сразу посмотреть интерфейс.

### Настройка (5 минут)

1. Зайди на https://console.firebase.google.com → «Добавить проект» (бесплатно).
2. В меню слева: **Authentication → Sign-in method → Email/Password → включить**.
3. **Project settings (⚙️) → General → Your apps → Web (`</>`)** → зарегистрируй веб-приложение,
   Firebase покажет объект `firebaseConfig`.
4. Открой `renderer/auth.js`, найди блок `const firebaseConfig = {...}` в начале файла и
   вставь туда свои значения вместо `YOUR_API_KEY` и т.д.
5. `npm start` — экран входа заработает по-настоящему: регистрация создаёт пользователя в
   Firebase, вход проверяет email/пароль, есть восстановление пароля по email.

### Как это устроено

- `renderer/auth.js` — ES-модуль, подключён как `<script type="module">`. SDK Firebase грузится
  прямо с CDN (`www.gstatic.com`) — бандлер (webpack/vite) не нужен. CSP в `index.html` уже
  разрешает нужные домены (`gstatic.com`, `identitytoolkit.googleapis.com`,
  `securetoken.googleapis.com`).
- Модуль кладёт API в `window.PulseAuth` (`signIn`, `signUp`, `signOutUser`,
  `resetPassword`) и рассылает событие `pulse-auth-changed` при изменении статуса —
  `renderer/renderer.js` его слушает и показывает либо экран входа, либо само приложение.
- Пока пользователь не вошёл, `.shell` (весь интерфейс) и плеер снизу скрыты классом `hidden` —
  ничего не подгружается из Deezer раньше времени.
- **Google-вход намеренно не сделан**: `signInWithPopup` в Electron ненадёжен (блокировки
  сторонних cookie в Chromium), корректно работающий OAuth-флоу через системный браузер —
  отдельная и куда более объёмная задача. Email/пароль — самый стабильный вариант для desktop.
- Известный нюанс: приложение грузится через `file://`, и в редких случаях Chromium может
  ограничивать IndexedDB для этого origin — тогда сессия просто не переживёт перезапуск
  (`setPersistence` оборачивает это в try/catch, ошибка не критична).

## Лайки и «Понравившиеся»

На каждом треке (в поиске, плейлистах, альбомах, плеере снизу) есть сердечко — клик добавляет
или убирает трек из личной подборки. Раздел **«Понравившиеся»** закреплён в сайдбаре сразу под
основной навигацией (розово-фиолетовая плитка с сердцем, как в Spotify) и дублируется первой
карточкой в «Медиатеке».

- Лайки сохраняются в `localStorage`, отдельно для каждого пользователя (ключ включает его
  `uid`/email; у гостя — общий ключ `guest`) — переживают перезапуск приложения.
- Список открыт как обычный плейлист: если убрать лайк прямо во время просмотра «Понравившихся»,
  трек сразу пропадает из списка.
- Хранится не только id, но и весь объект трека (обложка, исполнитель, превью-ссылка) — так
  раздел не зависит от повторных запросов к Deezer и работает даже если конкретный трек больше
  не найдётся через поиск.

## Моя волна

Пункт «Моя волна» в сайдбаре (сразу под «Главная») запускает бесконечное радио — аналог одноимённой
фичи Яндекс.Музыки: приложение само подбирает следующий трек и проигрывает их без остановки.

- Экран волны — отдельная «сцена»: большая пульсирующая обложка, кольца-пульсации вокруг неё
  (отсылка к названию Pulse), анимированный визуализатор из 5 полосок, три круглые кнопки —
  дизлайк / play-pause / лайк.
- **Дизлайк** — трек больше не появится в этой сессии волны, приложение сразу подбирает следующий.
- **Лайк** — обычный лайк, трек попадает в «Понравившиеся» (см. выше), сердечко сразу подсвечивается.
- Очередь пополняется на лету: сначала перемешиваются треки уже загруженного каталога (русская
  сцена, мировой чарт, твои лайки), а когда они заканчиваются — приложение подгружает ещё живых
  треков из Deezer по расширенному списку из ~20 артистов (`EXTRA_WAVE_ARTISTS` в `renderer.js`).
- Волна не останавливается при переходе на другие вкладки (Главная/Поиск/Медиатека) — играет в
  фоне, как обычное радио. Она отключается только если вручную запустить какой-то конкретный трек
  или плейлист — тогда управление возвращается к обычному режиму очереди.

## Дизайн

- Тёмный фон (`#0a0911`) + карточки на `#16131d`/`#1c1825`.
- Акцент — розовый `#ff2d79` с мягким свечением (glow) на кнопках, активных пунктах меню,
  лайках и прогресс-баре.
- Заголовки — плотный display-шрифт с отрицательным трекингом; лейблы/таймкоды — моноширинный
  шрифт (эффект «панели диджея»).
- Фирменный элемент — пульсирующее кольцо вокруг обложки в hero-блоке (отсылка к названию
  Pulse) и «эквалайзер» из 4 полосок на текущей обложке в плеере, когда трек играет.
- Уважает `prefers-reduced-motion` и имеет видимый focus-outline для клавиатурной навигации.

## Сборка в .exe/.dmg/.AppImage

Для дистрибутива добавь `electron-builder`:

```bash
npm install --save-dev electron-builder
```

и в `package.json` пропиши секцию `build` + скрипт `"dist": "electron-builder"`.
